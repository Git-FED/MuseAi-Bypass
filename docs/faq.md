# FAQ

## Is this a bypass tool?

No. It is a documentation catalog of safer access alternatives and hard-stop guidance.

## Does it host a website?

No. It includes only a local `index.html`; nothing is deployed and no Manus-hosted URL is created.

## Can I use a third-party viewer listed here?

Only after checking current availability, privacy, licensing, and terms. `HIGH`, `UNVERIFIED`, `DEAD`, and `NOT RECOMMENDED` entries should not be used as compliant routes.

## Can it log into my bank, email, or social account?

No. Use the provider's own OAuth or application and grant only the scope you understand. Never provide a password or session cookie to an intermediary.

## Why do some entries conflict?

The source refresh contains worker reports with different evidence and explicitly records conflicts, including Craigslist RSS status and Zillow's API retirement date. Re-check primary sources before acting.
