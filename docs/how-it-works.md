# How it works

This package is a static catalog. It contains Markdown notes and a local HTML index. There is no server, API proxy, browser automation, credential store, background job, or hosted URL.

The catalog organizes alternatives by service category and labels them by risk and confidence. Official APIs and public feeds are preferred. Third-party or fragile clients are clearly labeled, and routes that circumvent a gate are documented only as historical or unsafe categories rather than implementation instructions.

The source refresh reported conflicting and time-sensitive findings. The package therefore preserves the original source in `SOURCE_SPECIFICATION.txt` and uses cautious language in the generated summaries.
