# Setup

## View locally

From the repository root, open `clients/web/index.html` in a browser. No installation or network service is required.

Alternatively, read the Markdown files directly in any editor.

## Before using an entry

1. Open the provider's current primary documentation.
2. Confirm the route is available in your jurisdiction and for your use case.
3. Check authentication, rate limits, terms, licensing, attribution, and redistribution rules.
4. Use OAuth or a least-privilege token only when the provider authorizes it.
5. Stop on login walls, CAPTCHA, paywalls, DRM, MFA, geo-blocks, anti-bot responses, or rate limits.

This repository intentionally does not include credentials, configuration files, dependencies, installers, or a runnable bypass service.
