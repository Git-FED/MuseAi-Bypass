# Web client guidance

A web client in this repository means a public webpage, documented API, RSS/Atom feed, public dataset, or local browser-accessible tool that can be used without defeating a gate.

## Recommended selection order

1. Official API or public feed from the service owner.
2. Licensed partner API or a user-authorized integration.
3. Public dataset, library route, or subscription.
4. Established open-source client that does not require credential theft or access-control evasion.
5. Third-party service only after checking terms, privacy, provenance, and redistribution rights.

## Hard stops

Stop rather than work around login, paywall, CAPTCHA, DRM, MFA, private-account restrictions, geo-blocks, rate limits, or anti-bot controls. A page being technically reachable does not grant permission to automate or republish it.
