# Shared core principles

1. **Authorization first:** use only data and actions the provider makes available to the user or approved application.
2. **Least privilege:** request read-only scope where possible; never enable withdrawals, transfers, or destructive writes by default.
3. **Credential safety:** never accept another person's password, cookie, MFA code, API key, or recovery code.
4. **Hard stops:** authentication, paywall, CAPTCHA, DRM, MFA, geo-block, robots restriction, and rate limit are stop conditions.
5. **Provenance:** retain provider name, URL, date checked, status, and license/terms notes.
6. **User control:** make integrations revocable, visible, and easy to delete.
7. **No false certainty:** distinguish verified, unverified, degraded, dead, and historical entries.
