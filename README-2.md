# Web clients

This folder contains a static, read-only catalog of browser-accessible alternatives and official APIs. The catalog is informational only. Check each provider's current terms, authentication requirements, rate limits, and licensing before integrating.

Start with `index.html` for a simple local view, `web-clients.md` for the original 36-client catalog, and `browser-clients-simple.md` for the 92-entry compact list.
